## Implementation Details

### Data Processing Functions (client-side)

```typescript
// Process listings by month for bar/line chart
const listingsByMonth = listings.reduce((acc, listing) => {
  const month = new Date(listing.createdAt).toLocaleDateString("en-US", {
    month: "short",
  });
  acc[month] = (acc[month] || 0) + 1;
  return acc;
}, {});

// Process users by role for pie chart
const usersByRole = users.reduce((acc, user) => {
  acc[user.role] = (acc[user.role] || 0) + 1;
  return acc;
}, {});

// Process listings by status for pie chart
const listingsByStatus = listings.reduce((acc, listing) => {
  acc[listing.status] = (acc[listing.status] || 0) + 1;
  return acc;
}, {});
```
